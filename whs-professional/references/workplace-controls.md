# Universal Workplace Controls

Four universal workplace control areas that every WHS manager addresses regularly,
regardless of industry sector or organisation size: first aid, emergency
preparedness and evacuation, lone and remote work, and working from home /
hybrid arrangements. These are not hazard-specific — they apply across every
workplace, every PCBU, every contract. Use this file alongside `hazards.md`
(for hazard-specific operational detail), `legislation.md` (for statutory
provisions), and `inspections-audits-permits.md` (for assurance mechanisms).

## 1. First Aid in the Workplace

### Regulatory basis
Model WHS Regulation 42 requires the PCBU to ensure that:
- An adequate number of workers are trained to administer first aid at the workplace, or
- Workers have access to an adequate number of other persons who have been trained
  to administer first aid

The PCBU must also ensure first aid equipment is provided, the equipment is
accessible, and first aid facilities are provided. The benchmark for "adequate"
is set by the **Safe Work Australia Code of Practice — First Aid in the Workplace
(2019)**. Departing from the Code is permitted, but the alternative arrangement
must achieve a standard at least equivalent — and that justification needs to be
documentable.

In NZ, the equivalent obligation flows from the HSWA primary duty and the
Health and Safety at Work (General Risk and Workplace Management) Regulations
2016 (first aid duties), operationalised through WorkSafe NZ's first aid
guidance.

### Risk assessment for first aid
First aid arrangements are not a one-size template — they are the output of a
risk assessment specific to the workplace. The Code (s 2) sets out the factors
to consider:

| Factor | What to consider |
|---|---|
| Workplace type and hazards | Office, warehouse, workshop, construction site, laboratory, healthcare, outdoor/field — hazards and likely injury types vary materially |
| Workforce numbers | Total workers per shift; visitor and contractor numbers; peak occupancy |
| Shift patterns | 24/7 operations require coverage across all shifts; lone workers on back-of-house shifts |
| Geographic spread | Multiple buildings, multi-floor, multi-tenanted, large campus, remote field |
| Remoteness from medical services | Distance to nearest hospital, ambulance response time, helicopter capability |
| Emergency services response time | Metro 8–12 min typical; regional 15–30 min; remote 1 hour+ or limited |
| Worker characteristics | Age profile, pre-existing conditions, language, training history |
| Past incidents | Injury and illness history at the site; near-miss patterns |
| Hazardous chemicals on site | Specific antidote and decontamination requirements (cross-reference `hazards.md` §13) |

The risk assessment outputs: first aider numbers and competency level, kit
content and locations, additional equipment (AED, eye wash, emergency shower,
antidote stations), and the relationship with emergency services.

### First aider ratios
The Code of Practice provides ratio guidance based on workplace risk profile.
These are starting points, adjusted upward where the risk assessment shows
elevated factors (remoteness, shift coverage, dispersed workforce).

| Workplace risk profile | Code of Practice guidance | Examples |
|---|---|---|
| Low-risk workplace | 1 first aider per 50 workers | Office, retail, library, light commercial |
| High-risk workplace | 1 first aider per 25 workers | Construction, manufacturing, workshop, laboratory, agriculture, forestry, fishing |
| Remote or isolated workplace | 1 first aider per 10 workers + additional considerations | Mine site, remote construction, offshore, field crew at distance from medical services |

Practical interpretation:
- "First aider" means a currently certified first aider (HLTAID011 or higher,
  with CPR currency)
- Ratio applies to workers present at the time, not the total payroll
- Shift coverage is essential — a 1:25 ratio that disappears at 6pm leaves
  back-of-house, cleaning, and security workers without cover
- For dispersed sites (e.g., multi-building campus), each location must reach
  a first aider within a workable response time — a single first aider for the
  whole site does not satisfy the duty if access takes 15 minutes
- Remote site uplift reflects extended time to definitive care — more first
  aiders, higher competency level (HLTAID014 advanced), often supported by a
  site nurse or paramedic

### First aid kits — content and standard
There is **no Australian Standard prescribing workplace first aid kit
contents** — the Code of Practice itself is the benchmark, and it includes an
example contents list. (AS 2675-1983 *Portable first aid kits for use by
consumers* is a consumer kit standard, sometimes miscited as a workplace
requirement — it is not.) Commercial suppliers still market kits against the
legacy Type A / B / C classification, which remains a workable shorthand for
matching content to risk.

| Kit type | Application | Typical location |
|---|---|---|
| Type A (general) | Low-risk workplaces; basic content for general injuries (cuts, sprains, minor burns) | Office, retail, light commercial; back-of-house |
| Type B (high-risk / outdoor / remote) | Expanded content; includes additional trauma items, snake bite bandages, thermal blanket, specific items per environment | Construction, workshop, outdoor field work, rural/regional |
| Type C (vehicles) | Compact kit for vehicles; basic content for road incident first response | Fleet vehicles, mobile maintenance vans, sales vehicles |
| Specific environment / specialty | Marine, chemical, electrical, remote — supplemented per the environment | Workshops with specific chemical exposure, marine operations, remote field |

Each kit must:
- Be readily accessible (not locked in an office; signed location)
- Be visibly identified (white cross on green background — international convention)
- Have content matched to the workplace risk — generic kits in chemical-handling
  areas without chemical-specific items is a common audit finding
- Have a register identifying location, contents, responsible person, last check date
- Be checked at least monthly — expired items, missing items, contaminated items
  replaced

### Eye wash, emergency showers, antidote stations
For workplaces with hazardous chemical exposure (cross-reference `hazards.md` §13):

| Equipment | Standard | Application |
|---|---|---|
| Emergency eyewash and shower | **AS 4775:2007** *Emergency eyewash and shower equipment* | Required where chemicals capable of causing eye or skin injury are handled; location within 10 seconds travel (~16 metres) and on the same level as the hazard; tepid water 16–38°C; minimum 15 minutes flow |
| Plumbed eyewash | Drench shower combined with eyewash | Preferred for areas with corrosive or toxic chemical exposure |
| Portable eyewash | Single-use or refillable | For field, mobile, or low-volume applications; capacity ≥1 litre for 15 minutes flow at slow rate |
| Antidote stations | Per chemical-specific guidance | Cyanide antidote kit per current clinical advice (hydroxocobalamin has largely displaced older amyl nitrite kits); calcium gluconate gel (hydrofluoric acid handling); specific buffers and neutralisers |

Flushing equipment must be tested weekly (visual + functional) and serviced
annually per AS 4775. Contaminated, low-flow, or non-tepid equipment is a Major
NC at audit and a notifiable contributing factor in chemical injury incidents.

### First aid room
The Code of Practice indicates a first aid room should be considered where the
workplace is a **low-risk workplace with 200 or more workers**, or a
**high-risk workplace with 100 or more workers** — but these are indicative
triggers, not absolutes. The decision is risk-assessment-driven: a first aid
room should be provided wherever the assessment shows that administering first
aid at the workplace would otherwise be difficult (remoteness, injury type,
privacy, the need to stabilise a casualty pending ambulance arrival), even
below these numbers.

Where provided, the Code's indicative facilities and equipment for a first aid
room include:
- Located to allow easy access (including by stretcher or wheelchair), close to
  hand-washing and toilet facilities, and clearly signposted
- A bed or couch with waterproof surface, plus blankets and pillows
- A first aid kit appropriate to the workplace, plus a basin with running water,
  a cupboard for storage, and a chair and table or desk
- Electrical power points, adequate lighting and ventilation, and a telephone or
  other means of communication
- Where indicated by the risk assessment, an AED and additional equipment
  matched to the workplace hazards

A first aid room does not displace the first aider, kit, and AED arrangements
above — it supplements them for larger or higher-risk sites.

### Automated External Defibrillators (AEDs)
AEDs are not regulated as mandatory equipment under model WHS Regulations — but
their availability is strongly recommended by the Code of Practice, and the
absence of an AED where one would have plausibly intervened is increasingly
treated as a SFAIRP failure during incident review.

South Australia is the exception: the **Automated External Defibrillators
(Public Access) Act 2022 (SA)** mandates AEDs in prescribed public buildings,
facilities, and vehicles — Crown-owned from 1 January 2025; in-scope
privately owned buildings and public transport vehicles from 1 January 2026.
It is the first general AED mandate in Australia, and it sits in standalone
SA legislation, not the WHS regime.

**When an AED should be considered (Code guidance):**
- High occupancy workplaces (large offices, retail, schools, recreational
  facilities)
- Workplaces with elevated cardiac arrest risk — high-electrical-risk sites
  (electrical infrastructure work, substations), high-physical-exertion
  workplaces, workplaces with older worker demographic
- Remote or isolated workplaces with extended ambulance response time —
  defibrillation within 3–5 minutes of arrest is the strongest predictor of
  survival
- Workplaces with significant public access where the duty extends to "other
  persons"

**AED management regime:**
- Centrally registered with location, model, battery and pad expiry
- Sited in marked, accessible location — typically near reception, lift lobby,
  or first aid room; signed at corridor level
- Monthly visual check (status indicator, battery, pad expiry, child pad
  availability where applicable)
- Pad replacement every 2–5 years per OEM (single-use pads expire); battery
  replacement every 4–5 years per OEM
- First aider training should include AED use — HLTAID009 CPR refresher
  includes AED component
- Register with state ambulance service (NSW Ambulance, Ambulance Victoria,
  Queensland Ambulance Service, etc.) so the device appears on emergency triple-zero dispatch
  systems — when a member of the public calls 000 for a nearby cardiac arrest,
  dispatch can direct them to the registered AED

### First aider training — units of competency
First aid training in Australia and New Zealand is delivered against
nationally recognised units from the **HLT (Health) Training Package**, by
RTOs (Registered Training Organisations). Statements of attainment do not
formally expire — the currency periods below are Code of Practice and
Australian Resuscitation Council guidance (CPR refreshed annually; first aid
three-yearly), and workplace first aider registers should enforce them.

| Unit | Title | Currency | Typical application |
|---|---|---|---|
| **HLTAID009** | Provide cardiopulmonary resuscitation | **12 months** | CPR component; required to maintain HLTAID011 currency |
| **HLTAID010** | Provide basic emergency life support | 3 years (CPR 12 months) | Basic emergency life support; a current, separately accredited unit (narrower scope than HLTAID011) — less commonly used as the standalone workplace qualification, as most workplaces require HLTAID011 |
| **HLTAID011** | Provide first aid | **3 years** (CPR component 12 months) | Standard workplace first aider qualification — the default certification |
| **HLTAID012** | Provide first aid in an education and care setting | 3 years (CPR 12 months) | Childcare, schools, OOSH; covers anaphylaxis, asthma in children, ASCIA action plan |
| **HLTAID013** | Provide first aid in remote or isolated site | 3 years (CPR 12 months) | Remote workplaces with extended emergency response time |
| **HLTAID014** | Provide advanced first aid | 3 years (CPR 12 months) | Workplace first response coordinator; incident management, multiple casualty triage, advanced casualty care (oxygen therapy sits in HLTAID015) |
| **HLTAID015** | Provide advanced resuscitation and oxygen therapy | 3 years (CPR 12 months) | Lifeguards, emergency response teams, remote/marine |
| **HLTAID016** | Manage first aid services and resources | 3 years | First aid coordinator role — kit audits, training schedule, regulatory compliance |

Verify currency at engagement, not at incident — first aider rosters fall out
of date quickly when training is delegated without central tracking.

### Mental Health First Aid (MHFA)
Mental Health First Aid is a separate certification from physical first aid,
delivered by the Mental Health First Aid Australia program (an independent
training body). MHFA-trained staff are not clinicians — they are trained to
recognise signs of mental health crisis, provide initial support, and connect
the person to professional services.

| Course | Duration | Application |
|---|---|---|
| Standard MHFA | 2 days (12 hours) | Workplace mental health first aiders |
| Youth MHFA | 2 days | For staff working with adolescents |
| Aboriginal and Torres Strait Islander MHFA | 2 days | Culturally specific delivery |
| Refresher | 4 hours (every 3 years) | Maintain currency |

MHFA course structure and the recommended refresher duration/cycle are set by
MHFA Australia (an independent training body) and change periodically — treat
the hours and three-yearly cycle above as indicative and confirm against the
current MHFA Australia program before relying on them in policy or training
schedules.

MHFA is **not a substitute** for clinical mental health care, EAP, or
psychological injury response. It is a recognition-and-referral capability that
supplements physical first aid for the psychosocial dimension. Adoption is
increasing — many large PCBUs now run combined physical + MHFA first aider
networks, with MHFA capability promoted as visibly as physical first aid.

### First aid kit inspection regime
A documented inspection regime is required to satisfy the "ensure equipment is
provided" duty in Reg 42. Standard cadence:

| Activity | Frequency | Conductor |
|---|---|---|
| Visual check (kit present, accessible, sealed) | Weekly | Area supervisor / first aider |
| Content check (against contents list; expired items) | Monthly | First aider |
| Full audit (contents, location, register, training currency) | Annual | WHS team |
| Post-use restock | Per use | First aider who used kit |

A central register should track kit locations, responsible first aiders, last
check date, expired items pending replacement, and AED battery/pad expiry. For
multi-site portfolios, this is typically a single tracker visible to operations
and WHS — paper logs at each kit do not scale and are routinely abandoned.

### Coordination with emergency response
First aid is the first link in a chain that runs through emergency response,
ambulance handover, and hospital care. Coordination requirements:
- First aider equipped to brief paramedics on arrival — what happened, what
  was given, vital signs trend, allergies/medications if known
- Site address, building, level, and access point provided to triple-zero (000)
  caller — large sites and multi-tenanted buildings need a clear meet-and-greet
  protocol
- For sites with multiple buildings or restricted access, a marshal directs
  emergency services from the gate or entry point
- Casualty handover documented; first aider's notes retained (potential
  evidentiary value if outcome is poor or matter becomes notifiable)
- Where a first-aid event meets the notifiable-incident threshold (a death,
  serious injury or illness, or dangerous incident under model WHS Act ss 35–39
  / equivalent), the regulator must be notified immediately and the scene
  preserved until the regulator permits otherwise (cross-reference
  `legislation.md` §5)

Cross-reference §2 of this file — first aid sits within the broader emergency
response framework.

### Common failure modes
- Kit content not matched to workplace risk — standard office kit deployed in
  chemical-handling workshop
- Expired items not replaced; sterile items past use-by; medications past expiry
- First aider unavailable on shift — coverage gaps for back-of-house, cleaning,
  security, contractor crews
- No AED in remote or high-electrical-risk site
- First aider register out of date; nominated first aiders no longer employed
  or no longer current
- Eyewash and emergency shower not tested weekly; tested at "annual check" only
- Triple-zero caller unable to direct emergency services to the casualty
- No restock after use — kit unavailable for next incident

### Practical implications for FM / contract portfolios
- Multi-site portfolios (Government IFM, Education, Health) need a central
  first aider register linking sites, named first aiders, certification expiry,
  and kit locations — without this, the duty cannot be evidenced
- Contractor first aiders count toward site cover only where the contract
  scope and shift pattern reliably places them on site during the relevant
  hours; check before relying
- Cleaning and security shifts are commonly under-covered — the WHS team's
  daytime view of first aider numbers does not reflect 2am reality
- AED deployment across a portfolio is a defensible position to take to ELT —
  unit cost is modest (typically a low four-figure capital cost, roughly $1.5–3K
  depending on model; treat current pricing as verifiable), and the residual
  liability of not having one in a high-occupancy or remote site is substantial
- For multi-tenanted buildings, building manager and tenants have overlapping
  duties — clarify whose first aiders cover whose workers in shared areas
- Subcontractor prequalification should verify their first aider arrangements
  — not just the count, but the shift coverage and competency level

## 2. Emergency Preparedness and Evacuation

### Regulatory basis
Model WHS Regulation 43 requires the PCBU to ensure that an **emergency plan**
is prepared for the workplace. The plan must provide for:
- Emergency procedures (response to identified emergencies)
- Testing of the procedures, including frequency
- Information, training, and instruction to relevant workers
- Contact details of relevant authorities
- Medical treatment and assistance

The plan must be implemented in the event of an emergency.

The reference standard for emergency planning in Australia is **AS 3745:2010
*Planning for emergencies in facilities*** (incorporating Amendment 1:2014
and Amendment 2:2018). AS 3745 is
not legislatively mandated but is the recognised benchmark — departing from it
requires equivalent justification. The National Construction Code (NCC,
incorporating the Building Code of Australia) imposes parallel
emergency-management duties on building owners and managers via state
Building Acts.

In NZ, the equivalent flows from HSWA s 36 and is operationalised through
WorkSafe NZ guidance; the **Fire and Emergency NZ Act 2017** and the NZ
Building Code provide parallel duties on building owners.

### Emergency Plan elements
Per Reg 43, the emergency plan must cover specific topics. Mapped to AS 3745
structure:

| Element | Detail |
|---|---|
| Emergency types identified | Fire, smoke, chemical release, gas leak, medical, bomb threat, armed offender, severe weather, earthquake, tsunami (coastal), volcanic ash (NZ), flood, structural failure |
| Response procedures for each | Stop, raise alarm, notify, evacuate or shelter, account for personnel, liaise with emergency services |
| Emergency Control Organisation (ECO) | Named roles, deputies, contact details, training currency |
| Communication systems | Alarm system (audible, visible, paging), PA, internal radios, mobile phones, two-way for ECO |
| Evacuation diagrams | Per AS 3745 content requirements; located per occupant flow paths |
| Assembly areas | Identified, signposted, away from the building, accessible, communication-equipped |
| Roll call and accounting | Mechanism for accounting for workers, visitors, contractors, and others |
| Emergency services liaison | Site map, current chemical manifest, key holder contact, after-hours access |
| Specific provisions | People with mobility impairment, lone workers, contractors, visitors, after-hours workers |
| Testing and training | Drill frequency and types, ECO training, induction content |
| Plan review | At least annually, after any drill, after any incident, on building modification |

### AS 3745 — Emergency Control Organisation (ECO)
AS 3745 §5 establishes the ECO structure for facilities (guidance on
determining ECO numbers is at Appendix F). Member numbers and
roles scale to facility size and risk:

| Role | Function | Typical ratio |
|---|---|---|
| **Chief Warden** | Overall command of emergency response; liaison with emergency services on arrival; authorises declaration of emergency type and response | 1 per facility (with deputy) |
| **Deputy Chief Warden** | Assists Chief Warden; assumes command if Chief unavailable; manages communications | 1 per facility |
| **Communications Officer** | Operates communication systems (PA, alarm, phones); maintains contact with wardens; liaison with emergency services control room | 1 per facility (larger facilities — multiple) |
| **Area Warden / Floor Warden** | Manages emergency response in a defined area or floor; directs evacuation; coordinates with wardens | 1 per floor or major area |
| **Warden** | Sweeps assigned area; assists occupants; reports to Area Warden | Sufficient to sweep area within reasonable time — typically 1 per 20–30 occupants |
| **First Aid Officer** | Activates first aid response; coordinates with first aiders; liaison with paramedics | Per first aid arrangements (cross-reference §1) |

ECO members must be trained per AS 3745 §6 (ECO training §6.3; skills
retention §6.5) and must be identifiable during an emergency per §5.8
(coloured caps or helmets, hi-vis vest, ID). The standard leaves colour
choice to the EPC; the entrenched industry convention is white for the chief
and deputy chief wardens, yellow for area/floor wardens, red for wardens,
and green for first aid officers.

For multi-tenanted buildings, the building owner appoints a Chief Warden for
the building; each tenant appoints their own wardens for tenant areas — but
the ECO operates as a single command structure during an event.

### Evacuation diagrams
AS 3745 §3.5 prescribes evacuation diagram content (worked examples at
Appendix E):

- "You are here" marker (correctly oriented)
- Designated and emergency exits
- Communications equipment (alarm break-glass, phone)
- Manual call points
- Fire equipment (extinguishers by type, hose reels, fire blankets, hydrants)
- Assembly area location
- North orientation
- Floor or area identifier
- Validity date (review at least every 5 years; sooner on building modification)
- Legend with symbols

Diagrams must be located at building entrances, on each floor at the lift lobby
or stair head, and at significant decision points along egress routes. Mounted
at 1200–1600mm above floor level (accessibility consideration). Superseded
diagrams following building modification are a frequent audit finding —
diagrams must be updated when fit-out changes alter exit routes or fire
equipment locations.

### Emergency drills — frequency and type
AS 3745 §7 (emergency response exercises) requires an ongoing exercise
program, with each area participating in an evacuation exercise at least
annually. The higher cadences below come from sector regulation and practice
— not from the standard itself — and reflect building use and occupant
vulnerability.

| Facility type | Minimum evacuation drill frequency | Type variation |
|---|---|---|
| General commercial / office | Annual | Evacuation; occasional shelter-in-place |
| High-risk (manufacturing, laboratory, hazardous chemical site) | 6-monthly | Evacuation + chemical release scenarios |
| Healthcare (acute hospital) | Quarterly (some areas more frequent) | Evacuation + horizontal evacuation + shelter-in-place; full vs partial |
| Residential aged care | Quarterly | Evacuation + shelter-in-place + horizontal evacuation; account for resident mobility |
| Childcare and OOSH | Quarterly — rehearsal every 3 months per Education and Care Services National Regulations reg 97 | Evacuation + lockdown |
| Schools | Termly (typically) + annual full | Evacuation + lockdown + invacuation |
| High-rise commercial | Annual full + staircase / area drills more often | Evacuation + staged evacuation drills |

Drill types extend beyond evacuation:

| Drill type | Scenario |
|---|---|
| Evacuation | Building evacuation to assembly area; full or partial |
| Shelter-in-place | Hazard outside the building (chemical release, weather) — close windows, shut down HVAC intake, account for occupants inside |
| Lockdown | External threat (active armed offender, civil disturbance) — secure perimeter, lock down internal areas, communicate quietly |
| Controlled person | Internal threat (aggressive person, disturbed individual) — staff response, isolate, support, summon authorities |
| Tabletop / desktop | ECO walks through scenario response without physical action — useful for new ECO members, plan review |
| Walk-through | Physical walk of evacuation routes without full alarm; verifies route clarity |
| Full simulation | Alarm activated, all occupants evacuate, roll call conducted, debrief held |

### Fire safety — AS 1851 and statutory regimes
Fire protection equipment must be maintained per **AS 1851 — *Routine service
of fire protection systems and equipment***. The standard prescribes inspection,
testing, and maintenance frequencies for each system type:

| System | Typical service frequency |
|---|---|
| Portable fire extinguishers | 6-monthly inspection; 5-yearly pressure test; 10-yearly hydrostatic test (some types) |
| Fire hose reels | 6-monthly inspection; annual flow test |
| Fire hydrants | 6-monthly visual; annual flow and pressure test |
| Fire detection and alarm | Monthly check (some states); annual full test |
| Sprinkler systems | Weekly visual; monthly functional; annual + 5-yearly + 25-yearly progressively comprehensive |
| Emergency and exit lighting | 6-monthly 90-minute discharge test; annual |
| Smoke and fire doors | 6-monthly inspection |
| Fire pumps | Weekly start; annual full performance test |

Building owners have parallel statutory duties under state Building Acts and
the NCC for **Essential Safety Measures (ESM)** — annual condition reports
(Victoria's AESMR, NSW's annual fire safety statement, or equivalent) must be
issued and retained. Failure to maintain ESM is
a building offence separate from the WHS offence — councils and fire
authorities can issue notices and prosecute.

For FM contracts, the contractor's obligation to maintain AS 1851 systems is
often embedded in the scope but the building owner's ESM obligation remains —
clarify accountability at mobilisation.

### Specific emergency types
Beyond fire, the emergency plan must address scenarios specific to the site:

| Emergency type | Key planning considerations |
|---|---|
| **Chemical release** | Spill response, atmospheric monitoring, evacuation vs shelter-in-place decision logic, emergency services notification, manifest available (cross-reference `hazards.md` §13) |
| **Medical emergency** | First aid activation, triple-zero call, paramedic guidance, AED deployment, single-casualty vs multiple-casualty triage |
| **Bomb threat** | Threat assessment, evacuation vs search vs continuation, police notification, phone threat checklist for call recording (AS 3745 Appendix H; ANZCTC national guidance) |
| **Active armed offender** | Escape / Hide / Tell protocol (ANZCTC *Active Armed Offender Guidelines for Crowded Places*, adapted from the UK's Run / Hide / Tell; endorsed by AFP and state police); lockdown; communication discipline; post-event support. Lessons from Lindt Cafe siege (2014) and Port Arthur (1996) shaped contemporary planning |
| **Severe weather** | Storm, hail, cyclone, lightning, flood — shelter-in-place primary; building shutdown sequence; tree-fall and roof failure response |
| **Earthquake** | Drop / Cover / Hold On; post-shake building inspection before re-entry; aftershock awareness; relevant across all AU/NZ but high priority in NZ and parts of SA / VIC |
| **Tsunami** | Coastal AU (east coast, northern WA) and NZ — vertical evacuation to higher ground or upper levels; integrates with Bureau of Meteorology and NEMA / NEMA NZ warning systems |
| **Volcanic ash** | NZ central North Island, parts of Auckland — air handling shutdown, respiratory protection, dust egress; integrates with GeoNet warning |
| **Cyber / utility disruption** | Loss of power, water, comms, IT — emergency lighting and battery backup, generator start, alternate communication paths |

### Refuge areas and accessible egress
Buildings must provide for evacuation of people with mobility impairment.
The NCC's egress provisions provide, for certain building classes, accessible
**refuge areas** (e.g., fire-isolated stair landings with adequate space for
a wheelchair and one assistant); AS 3745 requires the emergency plan to
address occupants with a disability (key considerations §3.3; Personal
Emergency Evacuation Plan (PEEP) guidance at Appendix D). AS 1428 series
sets the access standard for the built environment.

The emergency plan must:
- Identify refuge areas and how they are reached
- Designate communication from the refuge area to the ECO (intercom, mobile,
  duress button)
- Document procedure for assisted evacuation — wardens trained, evacuation chair
  if used, fire service handover protocol
- Account for visitors with mobility impairment — sign-in process should flag
  assistance needs

Refuge areas blocked by storage, furniture, or rubbish are a high-frequency
audit finding and a serious failure — people relying on the refuge area cannot
self-rescue when conditions deteriorate.

### Emergency Services coordination
Pre-arrival information for fire, ambulance, police, and HAZMAT speeds
response and reduces error during the event:

- **Building plans** — current site plan, building plan, internal floor plan
  accessible to emergency services on arrival (key safe, fire panel, monitoring
  centre)
- **Current chemical manifest** — for Schedule 11 manifest quantities
  (cross-reference `hazards.md` §13); for sites below manifest threshold, a
  hazardous chemicals list with locations, quantities, SDS references
- **Site access information** — gate codes, after-hours contact, key holder
  details; updated whenever access controls change
- **ECO contact details** — Chief Warden, Deputy, after-hours emergency
  contact; updated on personnel change
- **Pre-incident planning** — for high-risk sites (MHF, hospital, university
  campus), pre-incident planning meetings with local fire brigade and
  ambulance management familiarise crews with the site

### Business continuity vs emergency response — the distinction
A persistent confusion in management planning. These are different disciplines
with different time horizons and different owners.

| Discipline | Time horizon | Purpose | Typical owner |
|---|---|---|---|
| **Emergency response** | Minutes to hours | Protect life and prevent escalation during the event | WHS / Facilities / ECO |
| **Crisis management** | Hours to days | Manage organisational impact, stakeholders, communications during the crisis period | Executive crisis team |
| **Business continuity** | Hours to weeks | Restore operations and services; alternate site activation; staffing continuity | Operations / Risk / IT |
| **Disaster recovery** | Days to months | Rebuild capability; insurance management; long-term restoration | Risk / Property / Finance |

Both **emergency response** and **business continuity** are needed — they are
not alternatives. An organisation with a well-drilled evacuation plan but no
business continuity plan is exposed to operational collapse after the
evacuation. An organisation with a sophisticated BCP but a stale evacuation
plan can lose people before continuity matters.

For WHS managers, the primary scope is emergency response; the WHS function
should however be a stakeholder in BCP development, particularly around
worker welfare, return-to-work after major events, and post-incident
psychosocial support.

### Test and exercise program
A defensible emergency preparedness program cycles through multiple exercise
types — drills alone do not prepare an ECO for atypical scenarios.

| Exercise type | Frequency | Participants |
|---|---|---|
| Desktop / discussion | Quarterly to 6-monthly | ECO; functional teams |
| Walk-through | 6-monthly | Wardens; physical route check |
| Full evacuation drill | Per AS 3745 cadence above | All occupants |
| Scenario-based drill (chemical, medical, lockdown) | Annual minimum | ECO + relevant teams |
| Joint exercise with emergency services | Every 2–3 years for higher-risk facilities | ECO + fire brigade + ambulance |
| Post-exercise debrief | After every exercise | ECO + WHS + facility management |

Debrief is where the learning happens — without it, drills become compliance
theatre. Findings are tracked, allocated owners, due-dated, and verified at
the next exercise.

### Common failure modes
- **ECO roles vacant** — wardens left, never replaced; Chief Warden role
  dormant; cover gaps not visible until an event reveals them
- **Drill compliance theatre** — drills announced, scripted, conducted at
  predictable time; no surprise element; no scenario variation
- **Contractor and visitor accounting** — roll call covers employees only;
  contractors, deliveries, visitors unaccounted for
- **Refuge areas blocked** — storage, rubbish, equipment in fire-isolated
  stairwells; refuge landings used as storage
- **Evacuation diagrams superseded** — fit-out changes have altered exit
  routes or fire equipment; diagrams no longer match reality
- **Assembly area co-located with vehicle traffic** — evacuated occupants
  exposed to secondary hazard
- **No after-hours arrangements** — emergency plan assumes business-hours
  presence; 2am cleaning shift, security guard, contractor — uncovered
- **No coordination with multi-tenanted neighbours** — adjacent tenant's
  evacuation triggers your evacuation but neither plan reflects the other
- **Triple-zero call fails to give clear address** — multi-building campus,
  high-rise, multi-tenanted; emergency services search for the casualty

### Practical implications for FM / contract portfolios
- Multi-site portfolios need a register of emergency plans by site, with last
  review date, last drill date, drill type, ECO membership current — the WHS
  team's annual cycle should hit each site, not just the central office
- For buildings the FM contractor manages but does not own, the building
  owner's ESM and emergency plan obligations remain — coordinate at
  mobilisation; document who owns what
- Contractor and subcontractor wardens count toward ECO numbers only where the
  contract reliably places them on site during relevant hours
- Lockdown protocols for facilities with public access (libraries, councils,
  health centres) are increasingly required — staff training a lever, not just
  a plan
- After-hours coverage — security, cleaning, maintenance — needs explicit
  treatment in the emergency plan; relying on "they'll see the alarm" is not
  a plan
- Post-event support — staff who evacuated through smoke, witnessed an injury,
  or were involved in a near-miss need access to EAP and structured debrief;
  this should be in the plan, not improvised after the fact

## 3. Lone Working and Remote Work

### Regulatory basis
Model WHS Regulation 48 imposes a specific duty on PCBUs for **remote or
isolated work**: manage risks SFAIRP, including by providing an **effective
system of communication** with the worker. The system must be appropriate to
the work — what works in the metro Sydney CBD does not work in the Pilbara.

In NZ, the equivalent flows from HSWA s 36 and is operationalised through
WorkSafe NZ's *Working alone* guidance.

The duty intersects with the psychosocial regulations (cross-reference
`legislation.md` §9) — remote and isolated work is a listed psychosocial
hazard category in the SWA Code of Practice 2022.

### Definition — remote or isolated work
Per the model reg 5 definition, echoed in the SWA *Managing the work
environment and facilities* Code of Practice:

> Work that is isolated from the assistance of others because of the location,
> time, or nature of the work being done.

"Remote or isolated" is not just about geography — it includes any work where
obtaining assistance would be difficult because:
- The worker is out of audio or visual contact with others
- Distance, terrain, or weather impedes response
- The time of day or shift pattern means few or no others are present
- The nature of the work limits ability to call for help (e.g., confined space
  entry, working at height, working in noise)
- Communication infrastructure is unreliable or absent

A receptionist working alone late at night in a CBD office, a community nurse
visiting a home, a security guard patrolling a remote site, a real estate
agent at an open home, a survey crew in the back country, and a long-haul
driver are all in scope.

### Risk assessment factors
| Factor | Considerations |
|---|---|
| Nature of the work | Routine or non-routine; physical risk profile; equipment use; client/public interaction |
| Geography | Distance from base; terrain; coverage maps; weather exposure |
| Communication coverage | Mobile coverage (multiple carriers, where applicable); satellite availability; two-way radio infrastructure |
| Time of day / duration alone | Daytime metro vs night shift remote; intermittent presence vs sole worker for full shift |
| Distance to medical / emergency services | Ambulance response time; nearest hospital; air ambulance capability |
| Individual worker factors | Medical conditions (declared); experience and competency; English language proficiency; physical capability |
| Aggression and violence risk | Client-facing roles; cash handling; lone retail; community visits to unknown residences |
| Vehicle dependency | If vehicle fails or worker cannot drive, what is the contingency |
| Environmental hazards | Heat, cold, wildlife (snakes, dogs), water, contaminated sites |

### Communication systems
The effective communication system required by Reg 48 must be matched to the
worker's actual circumstances. Options:

| Method | Application | Limits |
|---|---|---|
| **Mobile phone** | Where coverage is reliable; metro and most regional roles | Coverage gaps; battery; not effective if worker incapacitated |
| **Satellite communicator** (Garmin inReach, ZOLEO, Spot X) | Remote and back-country work; emergency SOS button; two-way text via satellite | Cost ($300–500 device + subscription); battery; latency |
| **Satellite phone** | Remote work requiring voice contact | Cost; physical size; requires line of sight to satellites |
| **Two-way radio** | Closed-loop sites (mine, large industrial, security network); repeaters cover defined area | Range limited; requires base station / repeater infrastructure |
| **Scheduled check-in (call or text)** | Most lone-worker contexts | Only as effective as the escalation when check-in is missed |
| **Lone-worker app** (e.g., StaySafe, SafeTCard, SoloProtect) | Automatic check-in, missed-check-in alerts, duress button, fall detection, GPS | Requires mobile coverage; battery; not all features work in all environments |
| **Personal duress alarm (fixed)** | High-risk client-facing locations (Centrelink offices, hospital ED, retail late shift) | Limited to fixed location; cover only when at the alarm |
| **Personal duress alarm (wearable)** | Community workers, parking inspectors, security guards | Battery; cellular dependency; centralised monitoring quality |

The communication system needs to do three things: let the worker call for
help when they need it, alert someone when the worker can't call (incapacitated,
under duress, in coverage dead zone), and enable response when the alert is
raised.

### Check-in protocol design
The check-in is the operational mechanism by which absence of contact triggers
response. Design considerations:

| Risk level | Check-in frequency | Examples |
|---|---|---|
| High risk | Hourly | Community workers in unfamiliar homes; remote single-occupant work in hazardous environment |
| Moderate risk | 2–4 hourly | Field maintenance work; survey crews; rural property visits |
| Low risk | Start and end of shift | CBD-based late-shift work with reliable mobile coverage and nearby support |
| Variable | Pre-arranged per task | Real estate open homes (per inspection); rural call-outs (per job) |

Escalation procedure when check-in is missed:
1. Wait one check-in cycle? Some protocols require immediate response;
   others allow a brief delay if comms are known to be patchy
2. Call the worker on primary number
3. Call worker on secondary number / send text
4. Call the worker's vehicle GPS or app GPS for last known location
5. Call worker's next of kin to confirm not at home / not unwell
6. Deploy field response — colleague, supervisor, on-call manager
7. Involve emergency services — police welfare check, ambulance, SES

The escalation must be **documented**, **drilled**, and **resourced**. A
check-in protocol with no defined response when check-in is missed is not a
control — it is paperwork.

### Journey management plans
For vehicle journeys of significant distance — particularly outside metro
areas — a journey management plan supports the check-in protocol.

Standard journey plan contents:
- Driver name, qualifications, fitness for work
- Vehicle (rego, condition, fuel, water, recovery equipment)
- Departure point, destination, planned route
- Departure time, expected arrival time
- Planned stops and check-in points
- Communication arrangements (mobile, satellite, scheduled calls)
- Weather and road condition assessment at departure
- Contingency for breakdown, weather, road closure
- Emergency contacts

For high-risk routes (single-lane unsealed roads, river crossings, remote
desert), the journey plan may require management approval before departure.

### Personal duress alarms — design choices
| Feature | Consideration |
|---|---|
| Trigger mechanism | Manual button (single or double press); auto-trigger on fall, no-motion, panic gesture |
| Voice connection | One-way (worker to monitoring centre) or two-way; recorded |
| Location | GPS for outdoor; Wi-Fi triangulation or BLE beacons for indoor (hospital wards, large facilities) |
| Monitoring | Centralised alarm monitoring centre (24/7 trained operators) vs peer monitoring (designated colleague's phone) |
| Response | Defined response protocol — who is dispatched, in what timeframe, with what authority |

Centralised monitoring through an A-grade security control room is the higher
assurance option — but cost is substantial. Peer monitoring is workable for
small teams but vulnerable when the peer is unavailable, distracted, or off
shift.

### Worker types with elevated remote-work risk
| Worker type | Specific risks |
|---|---|
| Community health and disability workers | In-home visits to unknown residences; client aggression; isolation; vehicle dependency; manual handling alone |
| Real estate agents | Open homes (unaccompanied with members of the public); after-hours inspections; high-value items |
| Surveyors, field engineers, ecologists | Remote terrain; environmental hazards; long days alone; communications limits |
| Agricultural workers | Property size; machinery operation alone; livestock; heat; communications |
| Long-haul drivers and operators | Fatigue (cross-reference `hazards.md` §18); journey hazards; cargo theft; remote breakdown |
| Security guards | Patrols alone; confrontation; out-of-hours; unfamiliar premises |
| Public transport operators | Passenger interaction; cash handling; late-night routes |
| Inspectors (parking, council compliance, regulatory) | Public confrontation; cash collection; mobile across area |
| Mining and oil and gas FIFO/DIDO | Remote work; camp accommodation; long rosters; mental health |
| Cleaners and maintenance after-hours | Empty buildings; lone access; equipment use alone |

### Aggression and violence — overlapping risk
The Code of Practice for psychosocial hazards explicitly lists workplace
violence and aggression as a psychosocial hazard requiring SFAIRP management
(cross-reference `legislation.md` §9). For client-facing lone workers, the
violence risk is the primary lone-work concern — not breakdown or injury,
but the person they are visiting.

Specific control approaches:
- Pre-visit risk screen — flagged client history, neighbourhood, time of day
- Two-up visits where indicated (not as default, but as a screened control)
- Vehicle parked for quick exit; visit conducted near door where possible
- Duress alarm and pre-agreed code word
- Pre-visit and post-visit contact with base
- Post-incident reporting and EAP referral
- Information sharing across services (with appropriate consent and privacy
  controls) about clients posing risks

### Vehicle as workplace
For workers spending substantial time driving, the vehicle is the workplace —
the WHS duty applies. Specific controls:

- **Vehicle selection and maintenance** — fitness for purpose, service history,
  safety rating (5-star ANCAP minimum for new procurement)
- **Fatigue management** — cross-reference `hazards.md` §18; for heavy vehicle
  drivers, Heavy Vehicle National Law (HVNL) applies; for light vehicle workers,
  the SFAIRP duty applies (e.g., journey duration limits, rest scheduling)
- **Mobile phone use** — handheld use prohibited in every state and territory
  under the road rules (phone-detection cameras operate in most
  jurisdictions); learner and provisional drivers face a total ban including
  hands-free in NSW and most states; voice-only communication;
  do-not-disturb whilst driving
- **Loading and securing** — load restraint per *Load Restraint Guide* (NTC);
  cargo barriers for commercial vehicles
- **In-vehicle hazards** — first aid kit, fire extinguisher (where applicable),
  recovery equipment for off-road; warning triangle, hi-vis vest, torch
- **Driver licensing and competency** — verify currency; defensive driving
  training for high-exposure roles; 4WD competency for off-road; HR/HC licence
  for combination vehicles

### Common failure modes
- **Assuming mobile coverage** — coverage maps reflect optimal conditions; in
  practice, terrain, weather, building shielding, and tower outages create
  gaps; a worker reporting "no signal" 5km from base does not have a
  comms system
- **Check-in escalation not tested** — protocol exists in document; never
  exercised; when triggered for real, response is improvised
- **Sole worker required to respond to emergency** — lone security guard
  responds to alarm at distant building; no backup; no defined response time
- **Lone-worker policy without equipment** — policy says "carry a communication
  device"; no device supplied or budgeted; worker uses personal phone
- **Duress alarm with no monitoring** — alarm triggers email; email reviewed
  next business day; not a control
- **Vehicle journey plans skipped for short trips** — incident on a 50km drive
  reveals no plan, no expected arrival, no contingency
- **Aggression risk not addressed** — lone work plan focuses on isolation and
  breakdown but ignores violence risk, which is the most common harm pathway
  for client-facing lone workers
- **After-hours backup unavailable** — escalation procedure assumes manager
  reachable; manager off-shift, on annual leave, or unreachable; no defined
  alternate

### Practical implications for FM / contract portfolios
- After-hours cleaning, security, and maintenance — these are the highest
  population of FM lone workers and the most commonly under-controlled;
  evaluate communications, check-in, and duress arrangements for every
  contract that places workers on site outside business hours
- Subcontractor lone workers count under your duty where you have engaged or
  directed them — verify their lone-worker controls at prequalification, not
  after the incident
- Mobile maintenance crews, security patrols, plumbing/electrical call-outs —
  journey management plans, vehicle inspections, fatigue scheduling
- Multi-site portfolios with shared workforce (e.g., regional maintenance
  technician covering 12 sites in a week) need explicit lone-worker treatment;
  the WHS plan at each site does not address the worker's journey between
  sites
- Lone-worker app procurement decisions are organisation-wide — fragmented
  adoption across BUs produces gaps and inconsistent escalation
- Pre-employment medicals for safety-critical lone work — declare medical
  conditions, medications, capability — supports fitness for work judgment

## 4. Working from Home and Hybrid Arrangements

### Regulatory basis — the home is a workplace
Model WHS Act s 19 imposes the primary duty on PCBUs in respect of workers
**"at work"** in any **"workplace"**. Workplace is defined in s 8 as a place
where work is carried out, and includes any place where a worker goes, or is
likely to be, while at work.

The home is a workplace for the period during which the worker is working
there. The PCBU's duty extends to the home workplace — to ensure, SFAIRP, the
health and safety of the worker.

This was contested during the early 2010s and emerged firmly in case law and
regulator guidance during the pandemic-era expansion of remote work. The
duty is now settled — **the question is not whether the duty applies, but
what is reasonably practicable to do at the home workplace**.

NZ position is equivalent: HSWA s 36 PCBU duty applies to the home workplace
for the working period (WorkSafe NZ *Working from home* guidance).

### What SFAIRP looks like at the home workplace
The PCBU cannot inspect every worker's home daily, install ducted ventilation
in a spare bedroom, or impose ergonomic furniture purchase mandates on workers
in rented accommodation. What is reasonably practicable looks different from
the controlled office environment:

- The PCBU can require a home workplace **self-assessment** against a
  defined checklist
- The PCBU can provide ergonomic **equipment** for sustained WFH (chair,
  monitor, keyboard, mouse)
- The PCBU can provide **training** on home workplace set-up, fatigue
  management, breaks, posture
- The PCBU can establish **policies** on working hours, after-hours
  contact, isolation check-ins, mental health support
- The PCBU can address **psychosocial dimensions** through team norms,
  manager training, EAP promotion
- The PCBU can require **escalation** of identified risks the worker cannot
  resolve unilaterally

What the PCBU cannot do — and is not required to do — is guarantee an
ergonomic, hazard-free home workplace. The duty is what is reasonably
practicable, not absolute.

### Home workplace risk assessment
The standard mechanism is a worker self-assessment against a structured
checklist. The PCBU reviews completed assessments, acts on identified risks
where reasonably practicable, and documents the outcome.

Typical checklist content:

| Category | Assessment points |
|---|---|
| **Workstation ergonomics** | Chair adjustable; lumbar support; monitor at eye level; keyboard and mouse position; desk height; feet supported; sustained-use vs occasional |
| **Lighting** | Adequate task lighting; minimised glare on screen; natural light; reading material illumination |
| **Electrical** | RCD on circuits; leads in good condition; sockets not overloaded; extension cords appropriate use |
| **Fire safety** | Smoke alarm in working order (legal requirement in all AU/NZ residences); clear exit path; fire extinguisher (recommended); fire blanket in kitchen (recommended) |
| **Slips, trips, falls** | Walkways clear; rugs secured; cables routed; stair condition; lighting at night |
| **Security** | Doors and windows lockable; reasonable security for work equipment and data; visitors during work hours |
| **Mental health and work-life** | Defined work area (separation from personal space); defined work hours; breaks; informal connection with colleagues; manager check-ins; awareness of EAP |
| **Family / shared occupancy** | Other occupants (children, partner, housemates); childcare arrangements during work hours; interruption management |
| **Environment** | Adequate ventilation; temperature comfort; noise level acceptable for concentration; not too isolated to feel safe |

The assessment is typically completed at:
- Commencement of WFH or hybrid arrangement
- Significant change (move, room change, family change)
- Annual or biennial review
- Following any reported injury or illness associated with WFH

### Equipment provision
For sustained WFH (not occasional or ad-hoc), ergonomic equipment provision
is the SFAIRP expectation. Standard provision:

| Equipment | Provision approach |
|---|---|
| **Chair** | Office-grade adjustable chair (height, tilt, lumbar, armrest); typically $400–800 |
| **Desk** | Adjustable height or fixed; sit-stand if budget permits; minimum dimensions for monitor + keyboard + paper |
| **Monitor** | External monitor 22"+ ; second monitor for dual-screen workflows |
| **Keyboard and mouse** | External (not laptop keyboard/trackpad for sustained use); ergonomic where requested |
| **Headset** | For sustained voice and video calls; noise-cancelling |
| **Laptop stand** | To raise laptop screen to eye level when used as second display |
| **Docking station** | For multi-monitor setups |

Provision approaches vary — full provision (PCBU buys and ships), allowance
(worker buys to PCBU specification, reimbursed), or BYO (worker uses own
furniture, with assessment). Full provision provides the strongest
defensibility; allowance is the most common in practice; BYO requires the
strongest assessment regime.

Workers compensation claims have followed WFH-related musculoskeletal injury
— laptop-on-kitchen-table arrangements for sustained periods are foreseeable
contributors. Documented offer of equipment, even where declined, supports
the PCBU position.

### Psychosocial dimension of WFH and hybrid
The psychosocial dimension is the most under-managed aspect of WFH —
typically because it is harder to see and the controls are harder to specify
than for ergonomic risk. The psychosocial regulations (cross-reference
`legislation.md` §9) apply equally to the home workplace.

Common WFH psychosocial hazards:

| Hazard | WFH manifestation |
|---|---|
| **Isolation** | Loss of informal connection with colleagues; reduced incidental conversation; mental health impacts |
| **Loss of role clarity** | Reduced in-person feedback; harder to know if work is on track; meaning loss |
| **Blurred work-home boundary** | Inability to disconnect; work creeping into evenings and weekends; presence anxiety |
| **Always-on communication** | Email, chat, video calls outside work hours; pressure to respond |
| **Presenteeism (digital)** | Mouse-jiggling, status-green-keeping, working while unwell |
| **Reduced informal learning** | Junior workers lose proximity-based skill acquisition from senior colleagues |
| **Family / domestic violence proximity** | Worker confined to a household with abuser; cross-reference below |
| **Loss of physical separation between work and life stress** | Home as both retreat and workplace; nowhere to "go home" to |

Control approaches:
- Team norms around hours, response time, channel use
- Manager training on remote management — regular check-ins, output focus
  over presence, mental health conversation skills
- Active EAP promotion (utilisation rates are lower for distributed workforces
  unless promoted)
- Hybrid scheduling that preserves in-person connection
- Workload management — visibility of demand and capacity at team level
- Wellbeing pulse surveys with action on findings

### Right to Disconnect
The Fair Work Act 2009 was amended by the **Fair Work Legislation Amendment
(Closing Loopholes No. 2) Act 2024** to introduce a **Right to Disconnect**.

| Provision | Detail |
|---|---|
| Effective date — non-small business employers | **26 August 2024** |
| Effective date — small business employers (<15 employees) | **26 August 2025** |
| Section | Fair Work Act s 333M |
| Scope | An employee may refuse to monitor, read or respond to contact from their employer outside of the employee's working hours, unless the refusal is unreasonable |

Factors in assessing whether a refusal is unreasonable include:
- Reason for the contact
- How the contact is made and level of disruption
- Whether the employee is compensated for being available
- Nature of the employee's role and responsibilities
- The employee's personal circumstances (caring responsibilities, etc.)

Disputes are resolved through the Fair Work Commission's stop-order
mechanism (similar to the bullying stop-order).

**WHS implications for PCBUs:**
- The Right to Disconnect intersects with the psychosocial duty —
  expectations of after-hours response are a job demand and a boundary
  hazard
- After-hours contact protocols need explicit treatment in policy:
  what contact is acceptable, what counts as emergency, what is the
  expectation for response
- Manager training on the Right to Disconnect is required (most large
  PCBUs ran updated training in mid-late 2024)
- Communication tooling defaults should support the Right to Disconnect —
  delayed-send, do-not-disturb, scheduled email, "out of hours" autoresponse
- The provision applies to all employees regardless of work location, but
  is particularly relevant for WFH and hybrid where physical boundaries
  between work and home are absent

The Right to Disconnect is a Fair Work Act provision, not a WHS Act
provision — but the underlying conduct (after-hours work expectation
creating burnout) is squarely within the psychosocial WHS duty. PCBUs that
manage one without the other create inconsistent obligations on managers.

### Family and domestic violence (FDV) intersection
The home is a workplace; FDV happening at home during work hours is, in
real terms, occurring at the workplace. This creates an evolving area of
PCBU duty and practice.

Operational reality:
- A worker experiencing FDV may be at heightened risk during work hours
  when at home with an abuser
- Indicators may be visible to managers and colleagues even remotely —
  unexplained absences, controlling phone interactions, visible injury on
  video calls, change in performance
- The PCBU has a WHS duty to identify foreseeable risks — FDV is now
  considered foreseeable in any workforce; risk assessment should address it
- The Fair Work Act provides **10 days paid family and domestic violence
  leave** annually (since 1 February 2023 for non-small business; 1 August
  2023 for small business)
- Workers compensation coverage for FDV-related injuries is mixed across
  schemes — in NSW, death benefits were upheld where a worker was killed by
  her de facto partner (also her co-worker) while working from home
  (*Workers Compensation Nominal Insurer v Hill* [2020] NSWCA 54); other
  schemes remain largely untested

Control approaches:
- Manager training on recognising and responding to indicators of FDV
- Confidential disclosure pathways
- Workplace safety plan for affected workers (changed contact details,
  altered patterns, secure systems access)
- EAP with FDV specialist support
- Reasonable adjustments — temporary office attendance, flexible hours,
  alternate accommodation support
- 1800RESPECT national hotline visibility; state FDV service awareness
- Our Watch *Workplace Equality and Respect* resources and Champions of
  Change Coalition guidance for policy and training (named third-party
  programs and hotlines are current at time of writing but can be rebranded or
  restructured — confirm the current service name and resource before
  publishing)

### Mental health and EAP for distributed workforces
EAP utilisation patterns differ for distributed workforces. Workers who
never come to the office may not see EAP collateral, may be less aware of
how to access services, and may face barriers to engagement (privacy at
home, unfamiliarity with provider).

Active promotion approaches:
- EAP details in email signatures and intranet
- Quarterly all-staff communication including EAP reminder
- Manager reminders during 1:1s and team meetings
- Anonymous engagement statistics published (utilisation rate, modalities,
  trends) without identifying users
- Onboarding includes EAP introduction
- Specific support for major events (organisational change, redundancies,
  industry shocks, public events)

### Hybrid arrangements specifically
Hybrid (mixed WFH + in-office) is the dominant pattern for office-based
work in AU/NZ post-pandemic. WHS considerations specific to hybrid:

- **Coordination of in-office days** — anchor days for team connection;
  flexibility for individual needs; visibility of who is where
- **Equity between WFH-capable and frontline workers** — workers in
  customer-facing, healthcare, manufacturing, FM and similar roles cannot
  WFH; perception of differential treatment is a real psychosocial dynamic
- **Hot-desking ergonomics** — shared workstations need to be adjustable
  (monitor, chair) for each user; common audit finding is fixed-height
  monitors in hot-desk environments
- **Hygiene of shared spaces** — cleaning regime visible; keyboards and
  mice; meeting room sanitiser availability
- **Manager training for hybrid teams** — output focus, presence equity
  (not penalising WFH workers in performance assessment), inclusion in
  meetings (no-one is "in the room" if some are remote)
- **Onboarding for new starters** — full remote onboarding produces
  isolation and disengagement; structured in-person time for first weeks
  supports integration

### Tax and insurance interactions
Outside WHS scope but flagged for PCBU awareness:

- **Workers compensation** — WFH injuries arising out of or in the course
  of employment are compensable in every scheme — NSW (icare), VIC
  (WorkSafe Victoria), QLD (WorkCover Queensland) and the rest; the contest
  is usually whether the activity was sufficiently work-connected
  (injuries during a recess break at home have been accepted since
  *Hargreaves v Telstra* (2011, AAT)). Journey claims (commuting to the
  office on a hybrid day) differ sharply by state — QLD covers them, NSW
  only with a real and substantial connection to employment, VIC generally
  not. FDV-related injury claims are evolving — see the *Hill* decision
  above. Cross-reference `compensation-rtw.md` §11
- **Tax** — workers may claim home office expenses (varies by ATO method
  in use); PCBU equipment provision is generally not assessable
- **Insurance** — PCBU public liability and contents insurance may have
  limitations on WFH; review with broker

### Common failure modes
- **Assuming WFH = lower-risk** — no assessment conducted; ergonomic
  and psychosocial risks accumulate invisibly
- **Equipment provision not offered** — workers improvise on kitchen
  tables and dining chairs; foreseeable musculoskeletal injury follows
- **Psychosocial risk not considered** — the WHS plan addresses ergonomic
  and electrical only; isolation, workload, blurred boundaries unmanaged
- **After-hours expectations create burnout** — Right to Disconnect
  obligations not reflected in manager behaviour; pressure to respond
  late and weekend remains; high turnover and psychological injury
  claims follow
- **Manager training absent** — managers default to presence-based
  management; remote workers feel surveilled or invisible
- **Hot-desking ergonomics ignored** — fixed-height monitors, shared
  chairs not adjusted, no docking station for laptops
- **FDV blind spot** — no manager training, no disclosure pathway, no
  safety planning capability
- **Onboarding by webcam** — new starters left to assemble understanding
  of the role, team, and tools without structured support

### Practical implications for FM / contract portfolios
- For client buildings under FM scope where the client has a hybrid
  workforce, the building's occupancy patterns change — lower density,
  variable peaks, different cleaning and security profile; FM scope
  should adjust to actual occupancy
- For the FM contractor's own workforce — coordinators, managers, schedulers
  — hybrid arrangements need home workplace assessment, equipment provision,
  psychosocial consideration consistent with the above
- Frontline FM workers (technicians, cleaners, security) cannot WFH —
  hybrid policy fairness needs explicit management to avoid two-class
  workforce dynamics
- For multi-tenanted buildings, the building owner / manager has limited
  visibility of tenant WFH arrangements; the WHS duties remain with each
  tenant PCBU for their own workforce
- Mobile and technician roles using a vehicle as their primary workplace —
  cross-reference §3 lone-worker and journey management; the home as
  "workplace" considerations apply equally to start-of-day and end-of-day
  arrangements

## 5. Output Checklist for Workplace Controls Tasks

Before finalising any output addressing first aid, emergency preparedness,
lone working, or working from home, confirm:

### First aid outputs
- [ ] First aider count matched to Code of Practice ratio for workplace risk level (1:50 low-risk; 1:25 high-risk; 1:10 remote)
- [ ] Shift coverage addressed — not just business hours
- [ ] Kit content matched to workplace risk; Type A / Type B / Type C selected appropriately
- [ ] Eye wash and emergency shower provision assessed where chemicals present (AS 4775)
- [ ] AED considered for high-occupancy, remote, or high-electrical-risk sites; placement and registration with state ambulance specified
- [ ] First aider training currency tracked (HLTAID011 3-yearly; HLTAID009 CPR 12-monthly)
- [ ] Mental Health First Aid capability considered alongside physical first aid
