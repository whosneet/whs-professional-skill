# Examples — Realised WHS Outputs

This folder holds worked example outputs that show what "good" looks like for
the common deliverables produced by the WHS Professional skill. Each file is a
fully-realised output, not a template — templates live in
`whs-professional/references/output-templates.md`.

The examples are calibration material. Claude (or a human practitioner) can
reference them to understand the expected voice, structure, and depth.

All examples use fictional organisations, sites, and incidents. Any resemblance
to real events is coincidental.

## Use

When asked to produce one of these output types, mirror the structure, depth,
and voice of the corresponding example. Don't copy content — substitute the
real subject matter. The examples illustrate calibration, not boilerplate.

## Adding examples

New examples are welcomed via pull request. Each should:
- Be a complete, realised output (not a template)
- Use fictional but plausible content
- Match the voice and structure of an existing template in `output-templates.md`
- Be filed under a numbered name with descriptive suffix
